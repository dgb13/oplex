# Cómo se manejan los impuestos y las retenciones

En **Contabilidad → Impuestos** está el catálogo de tasas impositivas, con historial versionado en el tiempo - si un impuesto cambia de alícuota, las facturas viejas no se alteran retroactivamente, siguen usando la tasa vigente al momento en que se emitieron.

También ahí se cargan los regímenes de retención (Ganancias, IVA, IIBB) que se aplican al pagarle a un proveedor, y los próximos vencimientos impositivos (IVA, Monotributo, etc.) si los cargás a mano.

Esta pantalla puede delegarse a un contador externo con acceso limitado - ver el artículo sobre Contadores para más detalle.
