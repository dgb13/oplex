# Qué es el catálogo visual y el carrito de Inventario

Sobre el listado normal de Inventario hay una vista tipo grilla (como un catálogo de e-commerce), con imagen, precio y stock de cada artículo. Desde ahí podés ir agregando artículos a un **carrito** propio de tu usuario, que queda guardado aunque cierres sesión.

Con ese carrito armado podés hacer tres cosas sin vaciarlo: repartir los artículos entre varios proveedores para pedir cotización a cada uno, proponerle la misma selección como venta a un cliente, o exportar todo a PDF. Ninguna de esas acciones vacía el carrito automáticamente - lo tenés que limpiar vos cuando ya no lo necesites.
