# Cómo gestionar clientes y proveedores (Empresas)

En **Empresas** se cargan tanto clientes como proveedores - de hecho, una misma empresa puede tener los dos roles a la vez (por ejemplo, un distribuidor al que le comprás y al que también le vendés). Cada una puede tener varios contactos (personas) asociados, condición de IVA, domicilio fiscal, y marcarse como proveedor preferido de ciertos artículos.

Al dar de alta una empresa podés buscarla por CUIT en el padrón de AFIP para autocompletar nombre y condición de IVA, en vez de tipearlo a mano.

Una empresa **no se borra**, se desactiva - así no se rompe el historial de facturas ya emitidas contra ella. Una empresa desactivada sigue apareciendo en reportes históricos, pero no se puede usar para operaciones nuevas hasta reactivarla.
