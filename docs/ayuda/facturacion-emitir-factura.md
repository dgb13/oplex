# Cómo emitir una factura

Andá a **Ventas → Facturación → Nueva factura**. Elegí el cliente (o creá uno nuevo ahí mismo), cargá las líneas de artículos o servicios, y confirmá. También podés facturar una cotización aceptada con **Convertir a factura**, o vender desde **Caja**.

Oplex sugiere automáticamente la **letra del comprobante** (A, B o C) según tu condición de IVA y la del cliente. Para poder facturar tenés que tener cargada tu condición frente al IVA en **Contabilidad → Conexión con ARCA**. Con el certificado de ARCA cargado, la factura sale con CAE; sin certificado se puede preparar pero no tiene validez fiscal.

Cómo se ven los importes según la letra:

- **Factura A**: precios sin IVA, con el neto gravado y el IVA de cada alícuota por separado.
- **Factura B**: precios finales con IVA incluido; abajo del total figura el "IVA contenido".
- **Factura C** (Monotributo o Exento): precios finales, sin IVA.

Se puede facturar en varias monedas (con tipo de cambio del día), aplicar bonificaciones por línea o un descuento general, sumar percepciones y elegir el formato del PDF (A4, A5 o ticket).
