# Cómo emitir una factura

Andá a **Ventas → Facturación → Nueva factura**. Elegí el cliente (o creá uno nuevo ahí mismo), cargá las líneas de artículos o servicios, y confirmá.

Oplex sugiere automáticamente la **letra del comprobante** (A, B o C) según la condición de IVA del cliente y la tuya propia - no hace falta elegirla a mano, aunque se puede forzar si hace falta. Si emitís con AFIP configurado (certificado cargado en Preferencias), la factura sale con CAE real; si no, queda igual el documento pero sin validez fiscal.

Se puede facturar en varias monedas (con tipo de cambio del día) y elegir el "concepto" (Productos, Servicios o Mixto), que cambia algunos datos que exige AFIP.
