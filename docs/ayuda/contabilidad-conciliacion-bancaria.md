# Cómo hacer la conciliación bancaria

En **Contabilidad → Reportes → Financiero** está la pantalla de conciliación. Podés importar el extracto de tu banco (con una plantilla propia de Oplex - descargás el modelo, lo completás con fecha/descripción/importe y lo subís) y el sistema intenta matchear automáticamente cada línea contra los movimientos ya cargados, por monto y una ventana de unos días de diferencia.

Lo que matchea solo queda conciliado; lo que no, queda pendiente para que decidas a mano - podés vincularlo a un movimiento existente, o crear un movimiento nuevo directo desde esa línea (por ejemplo, un gasto bancario que todavía no habías cargado).

No se puede importar el mismo archivo de extracto dos veces - el sistema lo detecta y avisa.
