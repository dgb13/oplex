# Cómo funciona el Ajuste por Inflación Contable

En **Contabilidad → Ajuste por Inflación** podés ver una vista previa del resultado por exposición a la inflación (RECPAM) para el rango de fechas que elijas, antes de decidir emitir nada.

Esto usa el índice de precios (IPC), que se sincroniza automáticamente todos los días desde una fuente pública - también se puede cargar o corregir a mano un mes puntual si hace falta. Cada cuenta del plan de cuentas está marcada como "Monetaria" o "No monetaria" (por ejemplo, Mercaderías es no monetaria); esa marca es la que determina cómo se recalcula cada una.

Cuando estás conforme con la vista previa, podés emitir el asiento definitivo con un clic - un mismo rango de fechas no se puede volver a emitir dos veces.
