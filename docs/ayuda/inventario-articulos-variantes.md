# Cómo cargar un artículo con variantes (talle, color, etc.)

En **Inventario → Nuevo artículo**, cargás los datos generales (nombre, categoría, precio) y después agregás las variantes: podés definir atributos libres (Color, Talle, o lo que necesites) y cargar varias combinaciones a la vez en vez de crear cada una por separado.

Un artículo puede marcarse como **"servicio"** si no maneja stock (por ejemplo, una hora de mano de obra), o como **"publicado"** si querés que aparezca en el catálogo visual tipo e-commerce.

También se puede importar una lista grande de artículos de una sola vez desde un archivo Excel, en vez de cargarlos uno por uno.
