# Cómo funciona el plan de cuentas y los asientos manuales

En **Contabilidad**, el plan de cuentas es configurable - podés ver, editar y agregar cuentas propias. La mayoría de los asientos se generan solos (facturación, cobros, pagos, compras), pero también podés cargar un asiento manual desde ahí cuando haga falta un movimiento que el sistema no genera automáticamente (por ejemplo, una venta informal sin factura).

El libro mayor te muestra el detalle de una cuenta puntual, y el balance de sumas y saldos da la foto completa de todas las cuentas. Un asiento ya cargado no se edita ni se borra - si te equivocaste, se revierte con un asiento de reversión, que queda como registro de ambos movimientos.
