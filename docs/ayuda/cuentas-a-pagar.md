# Cómo ver cuánto le debo a mis proveedores

En **Compras → Cuentas a Pagar** vas a encontrar el saldo pendiente por proveedor y un reporte de antigüedad de deuda, igual criterio que Cuentas a Cobrar pero del lado de lo que vos le debés a cada uno. También podés entrar al estado de cuenta detallado de un proveedor puntual.

Al registrar el pago de una factura de compra, si corresponde, se pueden cargar retenciones (Ganancias, IVA, IIBB) - se practican sobre lo que efectivamente pagás, no sobre lo que debés, siguiendo el criterio contable real.
