# Cómo manejar varias cajas al mismo tiempo

Cada caja física se da de alta por separado (desde el menú de usuario → **Cajas (POS)**, solo visible para Dueño/Administrador), y cada una lleva su propio historial de turnos, independiente de las demás.

Si hay varias cajas abiertas a la vez, en **Caja** aparece una posición consolidada en vivo: cuánto hay esperado entre todas, cuántas ya cerraron hoy, y si hubo diferencias. Sirve para tener una foto general del efectivo del negocio sin entrar caja por caja.

También podés elegir un tema visual distinto para el mostrador (claro, oscuro, alto contraste o esmeralda) desde la pantalla de venta - es solo estético, no afecta los montos ni el arqueo.
